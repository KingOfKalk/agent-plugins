## Accessibility

- WCAG 2.2 contrast minimum (1.4.3): https://www.w3.org/WAI/WCAG22/Understanding/contrast-minimum - text >= 4.5:1, large text >= 3:1.
- WCAG 2.2 non-text contrast (1.4.11): https://www.w3.org/WAI/WCAG22/Understanding/non-text-contrast - 3:1 for UI components and meaningful graphics. Card borders here are grouping, not controls, so the medium border color is accepted.
- Use of color (1.4.1): https://www.w3.org/WAI/WCAG22/Understanding/use-of-color - status is never shown by color alone.
